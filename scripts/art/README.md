# HypeMan art sources

The user-supplied pixel matrices and scene drawing routines originate in the supplied `HypeMan-2` folder. Only the artwork sources are retained here: the application is independently implemented, and the supplied application, audio, scene orchestration, and messaging code are not bundled. The wallpaper uses these authored drawing routines with a new silent, lifecycle-managed controller in `apps/extension/src/art/wallpaper.ts`. Run `node scripts/export-y2k-art.mjs` to render transparent props, rooftop layers, and the derived character animation atlas into `apps/extension/public/assets/y2k/`; matching demo artwork is exported into `apps/gateway/public/demo/assets/y2k/`.

The export preserves the supplied HYPEMAN graffiti lettering, original LCD jumbotron, city, clouds, blimp, CRT, pigeons, boombox, palette, and base character pose. Expressive animation frames and toolbar plates are derived from those supplied parts with whole-pixel articulation and hard alpha. The source folder originally provides one authored idle frame; additional states are derived animation work, rather than original authored poses. Scene export uses local Press Start 2P and VT323 font files, matching the supplied artwork typography. Press Start 2P is the unmodified Google Fonts release by CodeMan38 / The Press Start 2P Project Authors under SIL Open Font License 1.1; its license is packaged alongside the font as `apps/extension/public/assets/fonts/OFL-PressStart2P.txt`. The font comes from the [official Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/pressstart2p); runtime never fetches fonts remotely.

Generated PNGs ship directly, so normal builds do not require a browser or art regeneration. Preserve the user's ownership and any applicable notices.
